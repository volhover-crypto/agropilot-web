# Инструкции команде по новым блокам (ТЗ v1.1, сентябрь 2026)

Краткие инструкции по контурам «Маркетинг» и «Клиенты». Вход:
https://mdked.hlab.kz/agropilot/ (логин u1–u7; смена пароля — администратор).

## Оксана (редактор контента, u2)

1. **Медиа-мониторинг** (Маркетинг → 📰): A1 сам собирает материалы раз в час.
   «В работу» — берём в оборот, «Отклонить» — мусор, «В пост» — создать черновик.
2. **Контент и соцсети**: очередь черновиков (A2 пишет текст по материалу).
   Правите текст → «→ На проверку» → «✓ Одобрить в публикацию».
   «✨ Адаптировать (LLM)» — переписать под канал (указать стиль в диалоге).
3. **📅 Календарь**: клик по посту в «Без слота» → клик по дню — слот назначен.
4. «🚀 Опубликовать в Telegram» — только по вашему явному подтверждению.
   История правок хранится (версии), откат — вставить старый текст и сохранить.

## Катя (оператор, u1)

1. **Входящие**: обращения с сайта/соцсетей/почты. «🤖 Классифицировать (A4)» —
   тема/срочность/черновик ответа. «→ В лид» — обращение становится лидом.
2. **Клиенты**: карточка → «📋 Заполнить реквизиты по ИНН (ЕГРЮЛ)» — введите ИНН,
   реквизиты подтянутся сами (сбой источника — ввести вручную).
3. **Сделки**: карточка → «📄 Создать артефакт» — КП/письмо/договор по шаблону;
   в тосте будет список переменных, которые нужно дозаполнить.

## П. (разработчик, u7)

- **Настройки → Агенты**: карточки A1–A7, редактирование промтов с
  версионированием (каждое сохранение — новая версия; откат — PUT старого текста).
- n8n: https://mdked.hlab.kz/n8n (воркфлоу A1 активен).
- **Refresh-токен n8n истекает 28.09.2026**: login u7 → /v1/auth/refresh →
  обновить AGROPILOT_SERVICE_REFRESH в /root/n8n/docker-compose.yml →
  `docker compose up -d --force-recreate n8n`.
- Приёмочный тест: `U1_PASSWORD=... venv/bin/python scripts/acceptance_test.py`
  (10 критериев ТЗ; `--no-publish` — без реальной публикации в TG).

## Расписания (systemd)

- `agropilot-mia.timer` — наблюдения field_alerts, ежечасно.
- `agropilot-a6.timer` — утренняя сводка в Telegram, ежедневно 07:30 (МСК; часовой пояс сервера — Алматы, время задаётся явно Europe/Moscow).
